# Caps audit (2026-11-25)

Owner order (2026-11-25): remove every cap that stops a real page. Chrome does not count what a page makes. The JS heap and the process bound it.

This file lists each cap that can end a page or a call with a limit error, throw an exception that Chrome does not throw, or cut data without a word. The line numbers are for the commit that adds this file.

## Verdicts

- **remove**: the cap only counts things that a page may make. It goes.
- **keep**: the cap protects the process (native stack depth, a frame bomb), is a script budget, or only trims a diagnostic list. It stays.
- **owner**: a budget. The owner decides. This task does not change it.
- **follow-up**: a count cap that a later PR removes, or a cap that protects a slow algorithm. The algorithm is fixed first.

## Rules for the follow-ups

- A cap that bounds a list of native objects (observers, ranges, walkers, timers) goes when the objects are freed with their wrappers. Most are already freed by the collector.
- A cap that bounds bytes in transit (fetch bodies, WebSocket messages, queued messages) goes when the data is streamed or held in the JS heap.
- A cap that bounds a protocol field (HTTP/2 frame size, header list) stays when the protocol or Chrome has the same bound.

## Follow-ups

- **F1. Selector backtracking.** `dom-selector-complexity` refuses a selector with more than five descendant or later-sibling combinators. Chrome matches them. Fix the matcher (memoize the failed (compound, node) pairs, as Servo does for descendant combinators), then remove the check.
- **F2. Count caps of other modules.** Remove the count caps in sections 2 and 3 marked F2. Most are a single `if len >= MAX { return Err(lim) }`. Each needs a check that the objects are freed with their wrappers.
- **F3. Name table.** Names are never freed. A page that makes unique attribute names without end grows the table. Count references per name and free at the list rebuild.
- **F4. Geometry and computed style on large pages.** `GeometryLimits` and `ComputedLimits` stop reads on pages with more than 2^18 visible nodes or 2^17 nodes. The geometry depth bound is 96. Make layout iterative or bound it by the stack, then remove them.
- **F5. Tree depth.** Make native layout iterative, then remove `max_tree_depth`, `layout::block::MAX_DEPTH` and the geometry depth bound.
- **F6. Vex source size.** Remove `max_source` and `max_nodes` of the Vex parser (node indexes are `u32`). Needs the Vex cost rows.
- **F7. Text in one task.** The text list is rebuilt only between tasks. One task that rewrites text without end grows the list until 4 GiB (`dom-text`). Rebuild inside a task when no `Span` is borrowed, or make spans 64-bit.
