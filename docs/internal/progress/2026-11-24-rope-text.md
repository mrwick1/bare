# Text of a rope

Date: 2026-11-24.

## Problem

`Realm::text` gave the placeholder `<rope>` for a string that is a rope and is not flattened. Its comment said that it flattens a rope; it did not. About 50 callers use it. Two of them are `new Function` and indirect `eval`. So `new Function('a', 'b', "return {'q':function(){return " + "y" + " }}")` parsed the text `<rope>` and threw `SyntaxError: unexpected token`.

The Microsoft sign-in page builds its Knockout bindings this way. Each binding failed with "Unable to parse bindings", and the page stayed blank.

## Change

`interp_rt.rs`, `text`: a rope that is not flattened is read leaf by leaf, left to right, with a heap vector as the stack. The heap does not change, so `text` stays `&self`. Flat strings take the same path as before.

## Cost gate

`cost_matrix.sh -a -g 'js2_|console_load'`: 10 rows, glibc mean −0.001%, 0 over the rule. `console_load retain 10` fails on main too ("freed: 4999 != ?").

## Tests

- New: `builtins_function_ctor_tests.rs` (2 tests): a concatenated `Function` body compiles like its literal text; `eval` of a nested rope with a non-ASCII part, and a `Function` body made of three parts.
- `t`: all pass (909 Vex tests).
