# Add binary16 support to Vex

Add Float16Array, DataView float16 accessors, and Math.f16round. Round directly from binary64 to binary16 with ties to even. Preserve signed zero. Keep existing structured clone tags and assign a new tag to Float16Array. Web Crypto rejects Float16Array as a non-integer view.

The pinned buffer, typed-array, array iterator, and Math.f16round groups pass 2,819 cases in both verifier modes, with zero failures and 185 skips. All previous passes remain. Float16 support adds 44 buffer and typed-array passes and five Math passes.

The exhaustive conversion test round-trips all non-NaN binary16 encodings and checks NaN decoding. A browser integration test checks structured clone and the Web Crypto type error. Thirteen targeted tests and the all-target checks of Vex, the JS API, and bare pass.

On archMachine, the minimum of three alternating release runs per build and allocator across the five interp_load rows changes by -0.0039% to +0.0048%. The maximum spread within one row, build, and allocator is below 0.0091%.

Coverage excludes full Test262, browser journeys, dedicated Float16 throughput, and Windows.
