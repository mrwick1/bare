# js2 ArrayBuffer, typed arrays and DataView

## Changes

- Install the constructors and methods through the lazy built-in tables. Make the shared typed array constructor and prototype at first use.
- Store bytes in Blob cells. A view keeps its buffer alive. Resizing replaces the byte cell and preserves the bytes that still fit. Transferring detaches the original buffer and its views.
- Add the nine numeric typed array constructors. Add the requested methods and the shared `from` and `of` statics. Numeric properties read or write the buffer at their element offset. Array and typed array iterators share one prototype.
- Add DataView integer and floating-point reads and writes. The byte order defaults to big-endian. Typed arrays use the platform byte order.
- Implement the existing host methods for buffer creation, byte borrows, view metadata, detach checks and numeric element reads.
- Widen the kind field by one bit. Move the host-object flag to bit 19. Add the buffer tests to the Miri filter because the byte storage uses raw pointers.
- Leave the BigInt typed array constructors and DataView methods for the BigInt runtime. The suite also contains cases for Float16, immutable buffers and typed array methods beyond this change.

The implementation starts from PR #853. The measurement base includes the same merge with main as this change.

The new test262 directories cover ArrayBuffer, DataView, TypedArray and TypedArrayConstructors. The focused run passed 1,339 tests in these directories and all 26 ArrayIteratorPrototype tests. The existing skips for BigInt, cross-realm tests and the harness detach hook still apply.

Two previous passes hit the directory timeout in the generated RegExp cases. Both passed when the same runner ran them directly. No previous pass remained lost.
