# Run JSON callbacks and serialize wrapped primitives

JSON.parse calls the reviver for children before their holder. It deletes a property when the reviver returns undefined. JSON.stringify calls toJSON before the replacer. It converts wrapped values when it writes a value or reads the property list or spacing.

## Test262

This change fixes 25 old-only cases. It fixes ten in JSON.parse and 15 in JSON.stringify. The full baseline has 26,031 old passes, 26,507 new passes and 330 old-only cases.
