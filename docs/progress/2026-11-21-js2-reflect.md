# 2026-11-21: js2 `Reflect` (collections PR 2 of 2)

Branch `t3/js2-reflect`, stacked on `t3/js2-collections-reflect` (PR 1: [2026-11-21-js2-collections-reflect.md](2026-11-21-js2-collections-reflect.md), #828). Base for the cost rows: origin/main 287805fe, the same as PR 1.

## What changed

The census names 17 workloads that use `Reflect` (`RGet`, `RApply`, `RSet`, `RDefineProperty`, `RGetPrototypeOf`, `RGetOwnPropertyDescriptor`, `OwnKeys`). js2 had no `Reflect`. This PR adds the whole object, 13 methods.

- `crates/js2/src/bi_reflect.rs` (about 230 lines): thin wrappers over the object operations of `Realm` (`get_own`, `define_own`, `own_key_list`, `own_symbol_list`, `set_proto_checked`, `prevent_extensions`, `has_prop`, `delete_prop`, `construct_native`, `construct_script`). No new `unsafe`, no change in the collector.
- A failed operation gives `false`, not a `TypeError`. `get` and `set` take a receiver, so they walk the prototype chain by hand and call the accessor with the receiver. `defineProperty` reads the descriptor with `[[Get]]`, so accessors on the descriptor object run, in the order of the specification.
- `apply` and a getter in `get` use the tail channel: no native frame is added. `construct` handles a native target (with `new.target`) and a script function or class.
- Three lines outside the lane, as the brief asks to list: `bi_object.rs` `from_own` and `promise_statics.rs` `is_constructor` are now `pub(crate)`, and `set_proto_checked` returns false for `Object.prototype` (an immutable prototype exotic object; `Object.setPrototypeOf` gets the same fix).
- test262: `built-ins/Reflect` added to the subset. `allow:Reflect`, `allow:Reflect.construct`, `allow:Reflect.set` and `allow:Reflect.setPrototypeOf` added. `Reflect.construct` also lifts 40 skipped tests in the `Map`, `Set`, `WeakMap` and `WeakSet` directories.

## Tests

- `cargo test --locked -p bare-js2 --lib` (Linux): 571 tests, 571 passed (the 7 new ones are in `bi_reflect_tests.rs`). `cargo check --locked -p bare -p bare-js -p bare-js-api` passes. `cargo clippy -p bare-js2 --lib` shows nothing for the new file.
- The 7 tests run each script normally and under constant collection. They cover the shape of the object (names, lengths, attributes, `@@toStringTag`, not callable, not constructible), the `TypeError` for a non-object target in 11 methods, `apply` and `construct` (array-like argument lists, `new.target`, native and script targets, a `Map` subclass as new target), `get` and `set` with a receiver (accessors, `false` for a frozen object, a getter-only property, a non-extensible object and a read-only receiver property, an array `length`), `defineProperty` (descriptor read with `[[Get]]`, inherited fields, bad descriptors, `false` results), `deleteProperty`, `getPrototypeOf`, `setPrototypeOf` (cycle, non-extensible, `Object.prototype`), `ownKeys` order, `has`, `isExtensible`, `preventExtensions`, and a 300-turn loop under collection.

## Not tested

- Windows. A browser or journey run. Wall time.
- `Proxy` cases (js2 has no `Proxy`).
- `Reflect.ownKeys` on a plain function returns `length` and `name` but not `prototype` (hypothesis: the `prototype` property is made on first read; I did not check `Object.getOwnPropertyNames`).
- `new` on an arrow function or a method does not throw in js2, so `Reflect.construct(() => 1, [])` does not throw either. I saw `new (() => 1)()` and `new ({ m() {} }).m()` run without an error. The cause is in the compiler, outside this lane (hypothesis: `noctor` is not set for these functions).
