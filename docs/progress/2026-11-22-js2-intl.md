# 2026-11-22 — js2 Intl bindings stop at the startup gate

The branch installs `Intl` on the first lookup and creates each constructor on demand. It binds Collator and String localeCompare, DateTimeFormat, DisplayNames, NumberFormat with unit style, Locale, Segmenter construction and resolved options, RelativeTimeFormat, and ListFormat construction and resolved options to the shared Intl crate. Bound formatter functions keep their owners live. The collector removes formatter records when their owners die.

The standalone startup gate blocks the bindings. The branch remains local. The shared crate has its own pull request.
