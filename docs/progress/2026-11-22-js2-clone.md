# 2026-11-22 — Implement structured clone in js2

History state, structuredClone and messages use the shared clone record on js2. The writer assigns object IDs before it visits children. It snapshots own keys, then checks each descriptor before it reads the property. Listed items move only after the walk and all transfer checks succeed. The reader restores cycles, sparse and dense arrays, dates, regexps, collections, errors, wrappers, buffers and views.

The format recognizes the two BigInt typed array tags. js2 cannot read them because it has no BigInt typed array built-ins. Error records preserve an own string stack when the source has one.
