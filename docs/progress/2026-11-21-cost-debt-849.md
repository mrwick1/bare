# 2026-11-21: Generic browser cost debt from #849

Compare `1303414b` before #849 with `da9ba9af` after #849. Compare the verified fix tree `cfd2fd88` with `1303414b` for the cost rule. The fix tree includes main at `74f6611e` and the RegExp build fix from #862 (`6187ab08`). The examples below use the default engine selection.

## Changes

- Use a plain loop for the selector subject check. Keep the same traversal order and charge the same work.
- Move callback execution out of listener lookup. Keep the first turn on the stack. Allocate a vector only if more listeners match. Read each callback at its turn.
- Inline small DOM wrappers to remove calls around key lookup, object creation, strings and handle conversion.
- Install the old DOM through a concrete function in `bare`. A downstream child-page call can use that function with the host and source vtables that `bare` already builds.

## Measurement

On archMachine (Ryzen 9 5900HX, Rust 1.96.0), use the minimum of three `instructions:u` counts from `tools/js/cost_matrix.sh -J` for each binary and allocator. The filter includes every `cost_rows.txt` family from `crates/bare/examples`. Run with the default release profile and with `RUSTFLAGS="-C codegen-units=1"` on both trees. Use the profiling builds with symbols for Callgrind annotations.

## Callgrind

Use `callgrind_annotate --tree=caller`. The default builds keep symbols and leaf line tables. The single-codegen-unit builds use the profiling profile. Use the allocator and profile results below for the cost rule.

- Events and focus. The listener lookup moves out of `Dom::fire`. At default settings it calls `HashMap::get`. With one codegen unit it calls `RawTable::find`. In `focus_load focus 10`, 409,979 calls from `fire` account for 13.72 M instructions in `find` and its callees. `fire` itself drops by 9.80 M and `dispatch` grows by 3.50 M. The new snapshot avoids an allocation on a turn with one listener.
- Lookup. `Dom::query_s` grows by 9.12 M instructions at scale 10 in both builds. The selector subject loop grows from six instructions per turn to nine. `wrap_s` also moves out of its callers.
- Mutation observers. `Dom::key`, `Dom::js_str` and `Dom::obj` appear as calls in the record path. At scale 10 they account for 7.03 M self instructions with one codegen unit. At default settings `child_element_count` also grows by 7.35 M. The wrapper changes are sufficient with one codegen unit.
- Preload. The single-codegen-unit binary has two versions of the old host vtable methods. The loader relocation loop grows by 50,928 instructions. The relative relocation count grows from 27,974 to 32,218. It falls to 29,062 after the fix. At default settings the counts are 29,178, 34,089 and 31,300. The loopback workload also varies across samples.
